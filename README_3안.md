# 3안 | 가상 업무문서 근거 검색 (로컬 문서 검색 간이 PoC)

가상 문서에서 질문과 관련된 절/쪽/행을 찾아 **본문 인용 + 파일명 + 버전 + 위치**를 함께 보여 줍니다.

## 실행

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m py_compile app_3.py
python -m streamlit run app_3.py --server.address 127.0.0.1 --server.port 8503
```

브라우저: http://127.0.0.1:8503 (키트 루트에서 실행. 업로드 한도 5MB는 `.streamlit/config.toml`)

## 지원 형식 (`reference/loaders_3.py`)

| 형식 | 분할 단위 | 메타데이터(버전/분류/담당) |
|---|---|---|
| .md | `##` 절 | `- 버전:` 등 필수 |
| .docx | Heading 2 이하 절, 표는 `|` 구분 텍스트 | `버전:` 등 문단이 있으면 사용, 없으면 `미상` |
| .xlsx | 시트별 데이터 행(첫 행=헤더, `헤더: 값`으로 변환, 시트당 5,000행) | `미상` |
| .pdf | 쪽 단위 텍스트 | `미상` |
| .hwpx | 섹션 내 문단 8개 묶음 | 문단에 `버전:` 등이 있으면 사용, 없으면 `미상` |

- 업로드 파일은 **메모리에서만 처리**하며 서버 디스크에 저장하지 않습니다. 파일당 5MB(.md는 1MB) 제한.
- 내장 문서: `data/3안_가상문서/*.md`, `data/3안_다형식샘플/`(가상 docx·xlsx·pdf·hwpx; `tools/make_samples_3.py`로 재생성).
- 파일 단위로 성공/실패를 `문서 로딩 현황`에 표시하며, 한 파일이 실패해도 나머지는 검색됩니다.

## 한계
- 구형 `.hwp`(바이너리), 스캔본 PDF(OCR), 암호 PDF는 미지원입니다. `.hwp`는 `.hwpx`로 저장해 사용합니다.
- PDF·HWPX는 제목/절 구조를 알 수 없어 쪽·문단 묶음 단위이며, 표·다단 편집은 텍스트 순서가 어긋날 수 있습니다.
- 정확한 한국어 형태소 분석, 승인된 정본/접근 권한/문서 최신성 검증은 없습니다.
- **실제 사내·고객 문서를 업로드하지 마세요.** 보안 검토 전에는 가상 문서만 사용합니다.
