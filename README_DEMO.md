# 시연 가이드 및 수동 테스트

실행: `python -m streamlit run app.py` (README.md 참조). 모든 자료는 가상 더미데이터입니다.

## A. 시연 흐름 (약 10분)

**가상 저장소 3개 연결 → 문서 통합 수집 → 자연어 질문 → 권한 기반 검색 → 답변/근거 → 출처 확인 → 원본 위치**

| # | 조작 | 기대 화면 |
|---|---|---|
| 1 | 앱 실행 후 화면 확인 | 왼쪽 `검색 범위 및 필터`(사용자 `박계리(계리평가팀)`, 접근 가능 문서 13건, 저장소 3개 `정상`: 공유폴더 7 / 그룹웨어 3 / 업무시스템 3), 가운데에 검색 전 문서 목록(파일명·UNC 경로), 오른쪽 `관련 원문 미리보기` |
| 2 | 추천 검색 **"E101 오류 조치"** 클릭 | 파란 안내문 *"AI가 생성한 답변이 아니라 …"*, 결과 행마다 형식 배지·파일명·수정일·**UNC 경로**·일치 위치(예: PDF `p.2`, Excel `시트 '오류내역' · 셀 A2:C2`, PPT `슬라이드 3`) |
| 3 | PDF 결과의 `위치 열기` 클릭 → 오른쪽 패널의 UNC 경로 코드 블록 오른쪽 위 **복사 아이콘** 클릭 | 선택 위치가 노란색, 일치 단어 형광펜, `이전/다음 일치`로 위치 이동. 클립보드에 `\\fs-actu01.example.invalid\계리평가\결산검증\결산_내부통제_점검보고서.pdf` 복사 |
| 4 | 입력창에 **"모델 에러"** 또는 **"모델 실행 실패"** 입력 | 표현이 달라도 *RAFM 모델 실행 오류 대응 FAQ* 가 1위 (동의어 사전) |
| 5 | 사용자 **최재무(재무팀)** 로 전환 | 접근 가능 문서 7건. 같은 질문에서 FAQ·실행이력·계리 전용 Excel 등이 **전혀 보이지 않음** (제외 안내/건수도 없음). 위치 필터에도 접근 가능한 위치만 나타남 |
| 6 | 사용자 **관리자** 로 전환 후 "결산 검증 예외 승인 내역" 검색, 왼쪽 `공유폴더(UNC) 등록 · 관리` 열기 | 관리자 전용 문서(SF-004)가 관리자에게만 표시. 관리자만 공유 등록·해제 UI 가 보임 |
| 7 | 계리평가팀으로 돌아가 *답변 모드 설정* 에서 `AI 답변 모드` + `Mock LLM` 체크 후 "GoC 단위 변동 분석은 어떻게 하나요?" | *Mock 구조 테스트 응답* 표시, 답변 문장 끝 [1][2] 번호가 아래 근거 문단과 연결. **"실제 생성형 AI 아님"** 문구 확인 |
| 8 | 권한/문서 변경 시연: `data/` 의 파일을 수정(아래 B 참조) 후 왼쪽 **🔄 색인 갱신** | 변경 요약(신규/수정/삭제/권한변경), 결과·근거 패널·이전 답변이 자동 재검증됨 |
| 9 | "GoC 롤포워드 모델 실행 에러 질문 답변 댓글" 검색 | *그룹웨어 Q&A 게시글* 의 악성 문장 문단에 빨간 **⚠ 지시문 의심** 표시 — 실행되지 않고 AI 에도 전달되지 않음 |
| 10 | "휴가 규정의 육아휴직 수당은?" | "관련 문서를 찾지 못했습니다" 안내 (임의 답변 생성 없음) |
| 11 | "E101 오류 조치" 검색 후 왼쪽 **문서 유형 = Excel** 선택 | 검색 버튼 없이 즉시 Excel 결과만 남음. 형식·위치·수정일 필터를 조합해 결과가 좁혀지는지 확인 |
| 12 | **검색 대상 = 파일명만** 으로 "체크시트" 검색 → **본문만** 으로 바꿔 재확인 | 파일명만: `재무_결산_마감_체크시트.xlsx` 발견(본문 위치 없음) / 본문만: 결과 없음 |
| 13 | 정렬을 `파일명`, `수정일`, `경로` 로 바꾸고 내림차순 토글 | 결과 순서가 즉시 바뀜 (Everything 식 정렬) |
| 14 | 관리자로 `공유폴더(UNC) 등록`: 표시 이름 `신계약팀 공유`, UNC `\\fs-new01.example.invalid\신계약`, 가상 폴더 선택(사전에 `data/shared_folder/신계약팀/` 폴더와 문서 추가 필요) → 등록 | 등록 즉시 색인되고 위치 필터에 새 공유가 나타나며 새 문서가 검색됨. `C:\temp` 같은 잘못된 UNC 는 오류 안내 |

## B. 변경 시연용 파일 조작 (시연 후 `git checkout -- data` 로 복원)

| 시나리오 | 방법 | 색인 갱신 후 기대 결과 |
|---|---|---|
| 신규 등록 | `data/shared_folder/계리평가/가정관리/` 에 새 `.md` 파일 추가 (메타데이터 형식은 기존 파일 참고, 새 `doc_id`) | 신규 1건 감지, 검색됨 |
| 수정 | `data/groupware/posts/GW-002.json` 의 `body` 내용 변경 | 수정 1건, 최신 문구로 검색 |
| 버전 변경 | `data/business_system/records/BS-003.json` 의 `version` 변경 | 버전변경 1건 |
| 삭제 | `GW-001.json` 삭제 | 삭제 1건, 검색·열람·이전 답변에서 사라짐 |
| 권한 회수 | `data/shared_folder/계리평가/결산검증/IFRS17_결산검증가이드.md` 의 `allowed_groups: [actuarial, finance]` → `[actuarial]` (PDF/Excel/PPT 는 `.meta.json` 의 `allowed_groups` 수정) | 재무팀 사용자 결과·이전 답변에서 즉시 제외 |
| 공유폴더 경로 장애 | `data/shared_folder/재무공유` 폴더명을 임시 변경 | 갱신 상세에 `재무팀 공유 … 접근할 수 없습니다` 표시, 해당 공유 문서만 사라지고 나머지는 정상 (복원 후 갱신하면 복구) |
| 저장소 장애 | `data/groupware/posts` 폴더명을 임시 변경 | 그룹웨어 `연결 오류·검색 제외` 표시 + 상단 경고, 나머지 저장소는 정상 검색 (폴더명 복원 후 갱신하면 복구) |
| 형식 오류 | 공유폴더에 메타데이터 없는 `.md`, 또는 `.meta.json` 없는 PDF/손상된 xlsx 추가 | 갱신 상세에 "형식 오류로 제외" 사유 표시, 앱은 계속 동작 |

## C. 수동(브라우저) 테스트 체크리스트

자동 테스트(`python -m pytest`, 141건)는 앱을 브라우저 없이 구동하는 UI 테스트와, 실제 Chromium 을 조작하는 종단 테스트(경로 복사 시 클립보드 내용 검증 포함, 3건)를 포함합니다.
아래는 **눈으로 확인해야 하는 항목**입니다. 결과 칸은 시연자가 기입합니다.

| ID | 확인 항목 | 기대 | 결과 |
|---|---|---|---|
| M-01 | 3단 레이아웃, 네이비/화이트/그레이 톤, 글자 가독성 | 왼쪽·가운데·오른쪽 구분, 글자 잘림 없음 | ☐ |
| M-02 | 왼쪽 문서 목록 제목 클릭 | 오른쪽에 원문, 메타데이터·원본 위치 표시 | ☐ |
| M-03 | 분류 필터에서 `RAFM` 만 선택 후 검색 | 결과가 RAFM 분류만 | ☐ |
| M-04 | 저장소 필터 `업무시스템` 만 선택 | 결과가 업무시스템만 | ☐ |
| M-05 | 사용자 전환 시 이전 검색결과 | 이전 사용자의 결과가 남지 않음 | ☐ |
| M-06 | 이전 질문 내역 → `다시 검색` | 현재 사용자 내역만, 재검색 동작 | ☐ |
| M-07 | 권한 회수 후 `색인 갱신` | 회수 문서가 결과·원문 패널·이전 답변에서 사라짐 | ☐ |
| M-08 | 검색어 없이 `검색` | 경고만 표시, 오류 화면 없음 | ☐ |
| M-09 | 저장소 장애 시 | 상단 경고 + 저장소 상태 `연결 오류·검색 제외` | ☐ |
| M-10 | AI 모드 + Mock 미체크 상태에서 질문 | "실제 LLM 미연결" 안내 후 로컬 모드 결과로 대체 | ☐ |
| M-11 | 화면 폭을 줄였을 때(노트북) | 단이 세로로 쌓이며 사용 가능 | ☐ |
| M-12 | 결과 행의 UNC 경로 표기 | `\\서버\공유\...` 처럼 역슬래시 2개로 시작 | ☐ |
| M-13 | Windows 탐색기 주소창/실행창에 복사한 UNC 경로 붙여넣기 | 클립보드 내용이 정확히 붙음 (예약 도메인 .invalid 이므로 접속은 실패하는 것이 정상) | ☐ |
| M-14 | PDF/Excel/PPT 결과에서 `위치 열기` | 쪽/시트·셀/슬라이드 라벨이 있는 문단이 노란색으로 강조 | ☐ |
| M-15 | 수정일 `직접 지정` 범위 | 날짜 선택기로 범위를 정하면 결과가 즉시 갱신 | ☐ |

개발 중 확인한 범위: Streamlit AppTest 및 Linux 헤드리스 Chromium 으로 M-02, M-05, M-07, M-12~M-14 계열 흐름(경로 복사 포함)과 화면 캡처를 확인했습니다.
**Windows PC 의 실제 브라우저 확인은 미수행**이므로 위 표를 시연 전에 한 번 수행해 주세요.
