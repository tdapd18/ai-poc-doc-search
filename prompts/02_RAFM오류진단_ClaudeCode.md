# Claude Code에게 그대로 전달할 개발 지시문 — 2안 (교육 1순위)

당신은 Python 3.10+/Streamlit 개발자입니다. 현재 폴더에 `data/`, `reference/core_2.py`, `tests/test_core.py`, `DECISIONS.md`가 있습니다. **실제 RAFM 제품 연결이나 사내 로그를 요구하지 마세요.**

**목표**: 교육용 허구 LOG에 대해 ‘입력→오류 탐지→근거 줄→원인 후보→점검 순서’가 완결되는 `app_2.py` 웹앱 구현. 기존 `reference/core_2.py`와 자동테스트를 사양으로 고정하십시오.

**Must-have**
1. `data/2안_가상_실행.log` 와 `data/2안_오류사전.csv`를 기본으로 보여 주고 각각 업로드 가능. LOG 2MB, CSV 1MB, UTF-8/BOM만 처리.
2. 사전 필수 열 `code,pattern,severity,cause,check_steps`, code 정규식 `E\d{3}`, 중복 금지, 심각도 높음/중간/낮음 검증.
3. `[ERROR]`, `[WARN]`, `[WARNING]`, `[FATAL]` 줄만 검사. 코드 E###를 우선 추출하고 코드 없는 오류 줄은 사전의 pattern으로 보완. `[INFO]`는 무시.
4. `code` 별로 발생횟수, **원문 기준 1부터 시작하는 행 번호**, 원본 LOG 줄, 심각도, 원인 **후보**, ` > ` 구분 점검 순서 표시.
5. 심각도 높은순: 높음→중간→낮음→미등록. E999는 ‘추가 확인 필요’ 외 임의 진단 금지. 동점은 등장 줄번호 기준.
6. 빈 LOG/비UTF8/필수컬럼 누락/사전 중복코드에 오류 안내. CSV 다운로드(텍스트 수식주입 방지). 실제 RAFM 제어·자동수정 기능 제외.

**정확한 검증값**
- E101: 높음 / 2행 / 입력 파일 위치·이름 확인.
- E207: 중간 / 3행 / 헤더·컬럼명 확인.
- E320: 낮음 / 4행 / 기준월 일치 검토.
- E999: 미등록 / 5행 / ‘추가 확인 필요’, 점검 단계 없음.
- 총 탐지 코드 4, 등록 3, 미등록 1 (E101/E207/E320 세 종과 E999 별도).

**진행 방식**
- `tests/test_core.py` 16개 자동 테스트 통과를 유지하십시오. 에러를 숨기는 코드는 금지.
- 실제 Streamlit 브라우저에서 기본 샘플·빈 LOG·미등록 코드/다운로드 시연을 확인하도록 안내하십시오.
- 완료 보고 형식: **구현 기능 / 핵심 E101 화면 / 비정상 2건 / 테스트 결과 / 실행 명령 / 제한사항**.
- 실행: `python -m pip install -r requirements.txt` 이후 `python -m streamlit run app_2.py --server.address 127.0.0.1 --server.port 8502`.
