# Claude Code에게 그대로 전달할 개발 지시문 — 3안

당신은 Python 3.10+/Streamlit 개발자입니다. 로컬 폴더에는 `data/3안_가상문서/*.md`, `reference/core_3.py`, `tests/test_core.py`, `DECISIONS.md`가 있습니다. 실재 사내문서와 네트워크·LLM API를 사용하지 마세요.

**목표**: 가상 규정·모델·결산 문서에서 질문과 관련된 본문을 찾아 **출처까지 제시**하는 `app_3.py` 개발. 실제 생성형 RAG가 아닌 `로컬 문서 검색(간이 PoC)`으로 표기.

**Must-have**
1. Markdown 파일 3개 이상(현재 4개) 읽고 `# 제목`, `- 버전:`, `- 분류:`, `- 담당자:`, `## 절` 메타데이터 파싱. 파일당 1MB 제한.
2. ## 절 단위로 본문 수집. 원문 인용·문서 제목·파일명·버전·절 제목을 보존. 잘못된 문서에 대한 안내.
3. `reference/core_3.py`와 동일한 정규화·매칭 기준으로 검색: 한글/영문/코드 토큰, 지정된 일부 동의어(`체크할→점검`, `증감→변동`), 2개 토큰 또는 주요 도메인 키워드 일치, 점수순 Top3.
4. 관련 문서가 없으면 `관련 근거 없음`으로 표시하고 새 규정이나 답변을 만들어내지 않음.
5. 화면에 검색 방식(키워드 기반), 가상 데이터 여부, 문서 수 표시. 미래 확장만 README에 기재(임베딩·LLM은 현재 구현하지 않음).

**반드시 확인할 질문**
- `RAFM E101이 발생하면?` → 제목에 RAFM이 있는 가상 문서 E101 원문 절.
- `GoC 단위 변동 분석 방법?` → IFRS17 가상 결산변동 안내.
- `결산 전 체크할 항목?` → 교육용 결산 점검 체크리스트.
- `휴가 규정의 육아휴직 수당은?` → 결과 0건/관련 근거 없음.

**진행 방식**
- 문서/코어를 확인하고 기존 앱을 개선하거나 동일 규격으로 구현하십시오.
- `python -m unittest discover -s tests -v` 및 `python -m py_compile app_3.py`를 반드시 실행하십시오.
- 로컬 실행: `python -m streamlit run app_3.py --server.address 127.0.0.1 --server.port 8503`.
- 완료 보고: **구현 기능 / 질문별 결과 문서 / 거절(근거 없음) 테스트 / 출처 검증 / 한계 / 실행법**.
