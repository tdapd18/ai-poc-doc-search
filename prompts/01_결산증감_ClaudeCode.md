# Claude Code에게 그대로 전달할 개발 지시문 — 1안

당신은 Python 3.10+/Streamlit 애플리케이션 개발자입니다. 현재 폴더에 `data/`, `reference/core_1.py`, `tests/test_core.py`, `DECISIONS.md`가 있습니다. **실제 사내 데이터에 접근하지 마세요. 외부 LLM API, DB 및 네트워크 요청을 추가하지 마세요.**

**목표**: `app_1.py`의 ‘가상 IFRS17 결산 잔액 증감 분석’ 웹앱을 개선·완성하십시오. `reference/core_1.py`의 검증 로직과 `tests/test_core.py`를 정답 계약으로 간주하고, 변경할 때 테스트를 유지하십시오. 최초부터 다시 만든다면 동일한 인터페이스·동작을 구현하십시오.

**Must-have**
1. 파일 업로드 미선택 시 `data/1안_가상_결산.csv` 기본 사용. CSV 파일 UTF-8/BOM 수용, 최대 5MB.
2. 필수 컬럼 `period,goc_id,product_code,contract_key,liability_balance`; 선택 `reason_code`. 필수값/기간 YYYY-MM/유한 숫자/기간별 합성키 중복 검사 실패 시 집계 금지 + 오류 문구.
3. 두 기간 모두 실재하고 기준월 < 비교월이어야 함. 각 기간의 `(goc_id,product_code,contract_key)`를 합성키로 outer join; 없는 기간 잔액은 0. 기준-비교 순서 뒤집기 금지.
4. 전체 KPI(기준월,비교월,증감), GoC/상품별 증감표, 계약별 상세표, 절대 증감 상위 항목, GoC/상품 필터를 구현. 필터 적용 시 모든 합계 재계산.
5. 계약 상태 `신규/소멸/계속`, 사유코드는 가상 표시명 이상 해석하지 않음.
6. CSV 다운로드. Excel 수식 주입에 대비. 화면 상단에 ‘가상 데이터 및 회계 판단 아님’ 경고.
7. 예외 CSV를 사용한 안내 화면, 명령/환경/테스트 방법을 README에 설명.

**입출력 확정값**
- 기본 데이터: 2026-08 690, 2026-09 707, 총 +17.
- 상품: A100 +8, B200 +15, C300 +4, D400 -10. GoC: G1 +23, G2 -6.
- B200만 선택: 50→65 / +15. `1안_신규소멸_테스트.csv`: 100→30 / -70.
- `1안_컬럼누락_오류테스트.csv`: 결과를 내지 않고 누락된 컬럼명을 표시.

**진행 방식**
- 먼저 저장소 구조/가상파일을 점검하고 이 사양과 기존 코드의 차이를 보고하십시오.
- 누락된 기능을 작성하되 테스트가 깨지면 원인 해결 후 다시 진행하십시오.
- `python -m unittest discover -s tests -v`, `python -m py_compile app_1.py`를 실행해 실패가 있으면 고치십시오.
- Streamlit 실행이 가능한 환경이면 `python -m streamlit run app_1.py --server.address 127.0.0.1 --server.port 8501` 기동/브라우저 확인 방법을 알려 주십시오.
- 완료 보고 형식: **구현 기능 / 3개 정상 테스트 / 2개 예외 테스트 / 미구현 기능 / 실행 명령 / 보안 전제**.

**금지**: IFRS17 실제 부채측정, 회계 변동 원인 단정, BEST/DW 연결, 실제 증권번호 사용.
