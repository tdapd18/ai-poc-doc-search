# IFRS17 결산 검증 가이드

본 문서는 가상의 교육용 자료이며 실제 회사 규정이 아닙니다. 월말 IFRS17 결산 산출물을 검증하는 표준 절차를 설명합니다.

## 1. 검증 대상과 범위

검증 대상은 보험계약마진(CSM), 이행현금흐름(FCF), 위험조정(RA)의 산출 결과와 GoC(보험계약집단) 단위 롤포워드 결과입니다. 결산 검증은 모델 실행 완료 후 D+2 영업일 이내에 완료하는 것을 원칙으로 합니다.

## 2. 검증 절차

1. 입력 데이터 대사: 계약 건수와 책임준비금 원천 합계가 전월 말 대비 설명 가능한 범위인지 확인합니다.
2. 모델 실행 결과 확인: RAFM 실행 이력에서 실행 상태가 정상 종료인지 확인하고, 오류 로그가 있으면 오류 대응 FAQ에 따라 조치합니다.
3. 롤포워드 검증: 기초 잔액 + 변동 요인 합계 = 기말 잔액이 성립하는지 GoC 단위로 확인합니다.
4. 전월 대비 변동 분석: CSM 변동률이 ±5%를 초과하는 GoC는 변동 사유를 기록합니다.
5. 재무팀 정합성 확인: 회계 시스템에 인터페이스되는 금액과 계리 산출 금액의 차이를 확인합니다.

## 3. 허용 오차 기준

| 검증 항목 | 허용 오차 | 초과 시 조치 |
|---|---|---|
| 롤포워드 잔액 대사 | 1백만원 | 재실행 후 원인 분석 |
| CSM 전월 대비 변동률 | ±5% | 변동 사유서 작성 |
| 재무팀 인터페이스 금액 | 0원 | 즉시 팀장 보고 |

## 4. 검증 결과 기록

검증이 끝나면 업무시스템의 결산 검증 결과 보고서에 항목별 결과와 담당자 확인을 기록합니다. 불일치 건은 원인과 조치 계획을 함께 기재하고, 예외 승인이 필요한 경우 관리자 승인 절차를 따릅니다.
