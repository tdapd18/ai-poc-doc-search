# 계리적 가정 변경 관리 기준

가상의 교육용 기준서입니다. 해지율, 사망률, 사업비율, 할인율 등 계리적 가정을 변경할 때 지켜야 할 절차를 정합니다.

## 1. 변경 사유와 시점

계리적 가정은 분기 1회 정기 검토하며, 경험통계가 기존 가정과 유의하게 다른 경우 수시 변경을 검토할 수 있습니다. 가정 변경은 결산 마감 5영업일 전까지 확정해야 하고 마감 이후에는 다음 분기에 반영합니다.

## 2. 승인 절차

1. 담당자가 변경 제안서를 작성합니다. (변경 사유, 경험통계 근거, 영향 분석 포함)
2. 팀장이 타당성을 검토합니다.
3. 가정위원회가 변경 여부를 심의하고 의결합니다.
4. 최종 승인 후 모델 파라미터 변경 요청서를 작성하여 모델 운영 담당자에게 전달합니다.

영향 금액이 CSM의 3%를 초과하는 가정 변경은 반드시 가정위원회의 승인이 필요합니다.

## 3. 버전 관리

가정 테이블은 `가정ID_YYYYMM_vN` 형식으로 버전을 관리합니다. 이전 버전은 삭제하지 않고 보존하며, 변경 이력에 변경 사유와 승인일, 승인자를 남깁니다.

## 4. 사후 검증

변경된 가정으로 모델을 실행한 뒤 변경 전후의 결과 차이가 사전 영향 분석과 일치하는지 확인합니다. 차이가 10%를 초과하면 가정 반영 오류 여부를 점검하고 원인을 보고합니다.
