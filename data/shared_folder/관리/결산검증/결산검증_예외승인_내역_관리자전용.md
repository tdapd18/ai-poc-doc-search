# 결산 검증 예외 승인 내역 (관리자 전용)

가상의 교육용 자료입니다. 허용 오차를 초과했으나 관리자가 예외 승인한 건의 내역을 기록합니다.

## 1. 2026년 3분기 예외 승인

| 승인번호 | 대상 | 사유 | 승인자 | 승인일 |
|---|---|---|---|---|
| EX-2026-031 | GoC-C07 롤포워드 잔액 | 입력 데이터 지연 반영, 익월 정산 | 관리자 | 2026-08-04 |
| EX-2026-032 | 인터페이스 금액 차이 | 반올림 규칙 차이, 시스템 개선 예정 | 관리자 | 2026-09-02 |

## 2. 예외 승인 원칙

예외 승인은 허용 오차 초과 원인이 확인되고 다음 결산에서 해소될 수 있는 경우에 한해 관리자가 승인합니다. 예외 승인 내역은 결산 검증 결과 보고서에 별도로 표기하지 않고 본 문서에서만 관리합니다.
